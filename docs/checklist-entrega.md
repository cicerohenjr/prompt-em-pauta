# Checklist de entrega — DIO

## Materiais

- [x] Nome, tema e público definidos.
- [x] Roteiro e texto de narração organizados.
- [x] Prompts e uso das ferramentas documentados.
- [x] Capa PNG incluída.
- [x] Narração gerada e exportada em MP3.
- [x] Duração, codec, bitrate, taxa de amostragem, canais e loudness conferidos.
- [x] Voz e modelo registrados de acordo com o arquivo exportado.
- [x] Avaliação técnica do áudio documentada.
- [ ] O autor confirmar a pronúncia dos termos técnicos antes de publicar.

## GitHub

- [ ] Adicionar o arquivo binário output/episodio-01-prompt-em-pauta.mp3 ao repositório.
- [ ] Confirmar que a capa PNG está acessível publicamente.
- [ ] Confirmar que o MP3 pode ser aberto ou baixado no GitHub.

## Entrega

- [ ] Enviar o link do repositório GitHub no campo de entrega do desafio na DIO.
- [ ] Conferir a confirmação de envio.

## Observações

O pacote ZIP de entrega contém o MP3 atualizado, o roteiro, os prompts, a capa e a documentação. Para concluir a entrega pelo repositório, o MP3 binário ainda precisa ser adicionado ao GitHub.

O arquivo incluído usa Davi Andrei, modelo Eleven v4. O planejamento anterior mencionava The Professional Instructor; se essa voz for obrigatória, gere e revise uma nova versão antes de enviar.

Atribuição: ElevenLabs — https://elevenlabs.io. Se foi usado o plano gratuito, mantenha o uso não comercial e a atribuição ao publicar.
